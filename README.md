# Учебные задания по C++

Здесь собраны небольшие программы и фрагменты кода, которые я написал, разбирая C++ по шагам. Файлы идут от ввода и рекурсии к шаблонам, ручному управлению памятью и полиморфизму. Часть файлов самодостаточна, часть оставлена фрагментом или намеренно ошибочным примером, чтобы увидеть, где компилятор и санитайзеры ловят проблему.

## Ввод, вывод и алгоритмы

- `io1.cpp`, `io_data.txt`: читаю число пар и печатаю суммы. Первая строка файла задаёт количество пар.
- `io2.cpp`: решаю квадратное уравнение через дискриминант, проверяю `std::isnan` и привожу `-0` к `0`. Запуск читает один набор `a b c`.
- `io3.cpp`: сжимаю группы пробелов до одного, читая поток посимвольно через `std::cin.get`.
- `io4.cpp`: считаю целочисленный логарифм по основанию 2 повторным удвоением, граница типа `int64_t`.
- `gcd.cpp`, `power.cpp`, `reverse.cpp`, `rotate.cpp`: алгоритм Евклида рекурсией, возведение в степень циклом, разворот ввода через стек вызовов до нуля-признака конца, циклический сдвиг массива обменами.
- `max_element.cpp`: `std::min_element` и `std::max_element`, размер массива через `sizeof(arr) / sizeof(int)`.
- `max.cpp`: макрос `MAX(x, y, r)` на `decltype((x))`, чтобы аргументы вычислялись один раз и lvalue не потерял ссылочный тип.

## Строки и массивы

- `cstrings.cpp`: свои `strlen`, `strcat`, `strstr` на `const char*` и завершающем нуле.
- `getline.cpp`, `resize.cpp`: растущий символьный буфер, `new[]` и `delete[]`, копирование через `std::min`.
- `string_struct.cpp`: класс `String` с глубоким копированием, rule of three и защитой от самоприсваивания.
- `string_slice.cpp`: прокси `StringPart` для среза `hello[0][4]`, два последовательных `operator[]`.
- `array_size.cpp`: шаблон `array_size(const T (&arr)[Size])`, который не даёт массиву превратиться в указатель.
- `mdarrays.cpp`: двумерный массив в одном блоке памяти с таблицей указателей на строки, обмен строк через `std::swap`.
- `multidim_arrays_flatten.cpp`: две перегрузки `flatten` для `vector<T>` и `vector<vector<T>>`.
- `copy_n.cpp`: шаблон копирования `n` элементов с преобразованием через `static_cast<T>`.

## Шаблоны и типы

- `minimum_template.cpp`: функция `minimum` с компаратором как политикой сравнения и выводом типов аргументов.
- `template_array.cpp`: `Array<T>` на `unique_ptr<T[]>`, глубокое копирование и copy-and-swap.
- `template_array_2.cpp`: та же структура, но память через `operator new[]`, объекты через placement new и свой `Deleter<T>`. Время жизни объекта отделено от освобождения памяти.
- `partial_template_specialization.cpp`: свой `SameType<T, U>` с частичной специализацией `SameType<T, T>`.
- `value_holder_template.cpp`, `any.cpp`: стирание типа через `ICloneable::clone()`, `dynamic_cast` и собственный `Any` вместо `std::any`.
- `access_modifiers.cpp`: `private` проверяется компилятором, а не в памяти. Чтение полей через `reinterpret_cast` формально даёт неопределённое поведение.

## Классы, операторы и полиморфизм

- `oop_basics.cpp`: защищённый конструктор базы, создание объекта через производный класс и срез объекта при возврате базового значения.
- `rational.cpp`, `rational2.cpp`, `rational3.cpp`, `rational4.cpp`: перегрузка составных операторов с возвратом `Rational&`, свободные операторы с первым аргументом по значению для выражения `2 + a`, сравнение перекрёстным умножением, `operator double()`.
- `scoped_ptr.cpp`: владеющий указатель с единственным владельцем, `get`, `release`, `reset` и запрет копирования.
- `shared_ptr.cpp`: свой счётчик ссылок, control block, rule of three, защита от самоприсваивания и от `p.reset(p.get())`. В `main` 18 проверок.
- `virtual_basics.cpp`: виртуальный вызов через ссылку, невиртуальная `g()` внутри виртуальной функции и private-переопределение.
- `virtual_task.cpp`: дерево выражений `3 + (4.5 * 5)`, чисто виртуальный `evaluate`, рекурсивное удаление детей и эксперимент со сравнением vptr.
- `lifetime_test.cpp`, `test.cpp`, `test2.cpp`: висячая ссылка на локальную переменную, возврат ссылки на параметр и намеренно некомпилируемый синтаксис.

## Как запускать

`Makefile` собирает каждый `.cpp` в одноимённый `.out` с `-std=c++2c`, санитайзерами address, undefined и leak и строгими предупреждениями, превращёнными в ошибки.

```
make io1.out
./io1.out < io_data.txt
```

```
make shared_ptr.out
./shared_ptr.out
```

`make all` не подходит для всего каталога: многие файлы являются фрагментами без `main` или намеренно ошибочными примерами. Такие файлы я собирал точечно, чтобы посмотреть конкретную ошибку.

`compile_commands.json` содержит команды для 11 файлов. Путь `directory` в нём указан с другой машины.

## Результаты запусков

- `shared_ptr_mine.txt` и `shared_ptr_right.txt`: сохранённый и ожидаемый вывод старой версии тестов.
- Готовые бинарники и файлы `.out` в каталоге игнорируются через `.gitignore`.
